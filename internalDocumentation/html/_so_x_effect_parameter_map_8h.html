Detailed Description

The SoXEffectParameterMap specification defines a map of string keys and associated values of SoXEffectParameterKind; those values can be set and queried: this provides an interpretative coupling between audio processors and audio editors.

Entries can be set to active or inactive to provide a complete list of parameters to audio processors.
