Detailed Description

The package Effects provides types for the different audio effects themselves; the currently supported SoX effects are compander, chorus/echo/echos, filter, gain, overdrive, flanger/phaser/tremolo and reverb.

All the described effects inherit from base class AudioEffect that is defined in this namespace.

The plugins are based on the algorithms in the SoX repository based on the works of the SoX team namely Martin W. Guy, Chris Bagwell, Mans Rullgard, Rob Sewell, Ulrich Klauer, Lance Norskog and many others.
