Detailed Description

A _Compander object is a simple compander for several channels integrating the data point volumes and applying a transfer function to them; as opposed to a _MCompanderBand there is no crossover filtering done here, but a compander band uses the basic functionality of a compander and splits its output into a local and propagated result list.
